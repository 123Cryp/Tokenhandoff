OTC NFT sales, settled on proof of delivery.

Buyer and seller each lock a bond. The sale is anchored on-chain to one contract, token id and standard. The contract reads Blockscout data field by field: exact token, right parties, successful transaction, in time, and still held by the buyer. A staked jury can overturn the automated outcome.

You are the buyer (party A) and your bond is escrowed now. The seller (party B) must match it exactly to accept. The sale price itself is settled off-chain.

Recorded on-chain now. Delivery counts only for exactly this contract, token id and standard (and quantity for ERC-1155).

Blockscout explorer(s) of the chain the NFT lives on, comma-separated, for example eth.blockscout.com. List only explorers of that one chain: the same contract address on another chain would otherwise count. Evidence must be a Blockscout v2 API link on one of these hosts.

Unticked: the buyer must still own the token when the trade is resolved, so a transfer that was routed on to another address cannot count as delivered. If the token has moved on by then, the trade ends UNDETERMINED and each bond is returned. Tick it only if the buyer may sell it on.
